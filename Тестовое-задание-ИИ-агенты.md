Тестовое задание — Инженер по ИИ-агентам   ·   Стр. 2  Цикл:   опросить входящие → на каждое НЕпрочитанное письмо прогнать LLM tool-loop с телом письма как запросом → ответить письмом отправителю.   Письмо = единица диалога.  3.1 Канал (основной) — Outlook COM/JACOB  •   За интерфейсом   MailChannel : как минимум   List<Msg> fetchUnread()   и   void reply(Msg, String body) .  •   Реализации:   OutlookMailChannel   (JACOB)   и   MockMailChannel   (для тестов).  •   Идемпотентность (обязательно):   каждое письмо обрабатывается   ровно один раз ; состояние «обработанных» переживает рестарт процесса (seen-store на диске). Ключ дедупликации —   стабильный идентификатор письма   (Outlook   EntryID   /  Message-ID ), не тема/тело. Без этого poll-loop будет отвечать на одно и то же письмо каждый цикл — это считается дефектом ядра.  3.2 LLM  •   Интерфейс   LlmClient :   chat(messages, tools) → response . Реализации: HTTP   и   мок.  •   Ключ/секрет —   только из переменной окружения   (имя env задаётся в конфиге).  3.3 Инструменты (≥2; контракты можно спроектировать самостоятельно)  Рекомендуемый набор, детерминированный и тестируемый: -   current_datetime()   → текущее время ISO (через   инжектируемый   Clock   — чтобы тесты были детерминированы); -   add_reminder(text, dueIso)   → запись в локальный JSON-стор; -  find_items(query)   → поиск по стору.  3.4 Tool-loop  •   Ограничение числа шагов   maxSteps .  •   Устойчивость к кривому/галлюцинированному   tool_call : не падать — вернуть модели ошибку и корректно завершить.  3.5 Конфиг (YAML)  llm.endpoint/model/apiKeyEnv/timeoutMs ,   agent.maxSteps ,   store.path ,  mail.pollSeconds/profile/folder .   Никаких секретов в коде или git.  3.6 Graceful-фолбэк  •   LLM недоступен/таймаут → понятный ответ-письмо   или   пропуск + WARN;   никаких stacktrace пользователю .  •   Ошибка COM → WARN, цикл   не падает   (обрабатываем следующее письмо).  3.7 ПДн и безопасность (обязательно)  •   Письма содержат   персональные данные .   Не логировать тела писем/ПДн в открытом виде   (не писать в лог, либо маскировать).
